# 研究设计与统一实验协议

## 1. 任务解释

源数据是Shadow Hand轨迹 `q_s(t)=[p_w(3), euler_w(3), q_hand(22)]`。对每种目标手h，输出 `q_h(t)=[p_w(3), euler_w(3), q_h(J)]`，其中J分别为6、12、20。重定向的最终目标不是视觉相似，而是在统一Isaac Gym物理设置中重放时将物体抬升约0.30米。

## 2. 数据冻结

完整数据到位后先建立包含真实类别标签的inventory。使用固定seed 20260808，从至少有2个合格物体、每物体至少10条轨迹的类别中随机抽50类；每类随机抽2个物体，每物体随机抽10条轨迹，恰好100物体和1000条轨迹。manifest记录源文件、轨迹下标、文件哈希、类别和资产路径，之后不因结果好坏更换样本。

调参使用每个物体前2条由manifest预先随机指定的calibration轨迹，最终报告仍评测全部10条，并额外报告剩余8条的held-out结果。进阶策略必须按物体划分；具体train/test口径等待联系人确认，不能按帧随机切分。

## 3. Baseline B0：参考关键点IK

为Shadow与目标手定义语义点：掌心、五指近端/中端/指尖。每帧通过SLSQP最小化对应关键点世界坐标MSE，约束目标关节上下限，并以上一帧最优解热启动。腕部先做固定坐标轴对齐，输出保持70帧。XHand直接复现参考实现；LinkerHand修复零关键点；WujiHand新增运动学wrapper和评测环境。

## 4. 改进算法

建议的统一目标为：

```text
L = w_pos L_keypoint
  + w_vec L_palm_relative_vector
  + w_contact L_contact_preservation
  + w_normal L_surface_normal
  + w_pen L_penetration
  + w_vel L_velocity
  + w_acc L_acceleration
  + w_reg L_joint_regularization
```

`L_keypoint`保持语义点位置，`L_palm_relative_vector`匹配掌心到各指节的方向与相对长度，降低不同手尺度影响。`L_contact_preservation`只在Shadow轨迹接近物体表面的语义部位上激活，保持目标手对应部位到物体的近接距离；`L_surface_normal`避免只到达表面却从错误方向接触。`L_penetration`利用物体SDF或最近点惩罚明显穿透，`L_velocity/L_acceleration`保证整条轨迹连续，`L_reg`防止关节贴limit和不自然形态。

优化采用两阶段：第一阶段逐帧快速IK得到可行初始化；第二阶段以滑动窗口或整段轨迹联合优化平滑与接触。最后只在calibration集搜索每种手共享的腕部offset、闭合增益、时间缩放、PD刚度/阻尼和抬升段参数，不能针对最终失败轨迹逐条手工修补。

## 5. 三种形态的特殊处理

LinkerHand O6有6个主动关节和5个mimic关节，无法逐关节复现Shadow，目标应强调拇指对掌和五指指尖包络，弱化中间关节精确匹配。XHand有12个独立关节，保留参考仓库14个关键点映射作为强基线，再加入接触和时序项。WujiHand每指4个独立关节共20DOF，形态最接近Shadow，应建立更密集的一一语义映射，但必须正则化以避免高自由度过拟合关键点而产生自碰撞。

Linker开发实验进一步表明，单点距离、表面法向和离散摩擦锥即使几何上更合理，也未稳定转化为O6物理成功。开发v2采用统一渐进夹紧、固定6主动关节正负残差和输入条件两档PD，在10条上得到1/10→3/10→4/10→5/10；但冻结后在10个新物体20条上，几何基线/夹紧/固定残差/自适应PD分别为4/20、7/20、6/20、6/20。因此后续正式主方法选择泛化更好的统一渐进夹紧v1和默认PD 120/5；固定残差及自适应控制只保留为“开发提升未泛化”的消融。独立20条已用于方法选择，最终结论只看之后的正式heldout。

同一独立20条上，XHand官方参考为14/20，冻结真实指腹细化为16/20，新增Saucepan37和FruitBasket32且没有丢失原成功，因此正式保留指腹v1。Wuji v1/v2分别为16/20和12/20：v2关键点误差1.96 mm远低于v1的11.82 mm，却净少4条成功，因此正式选择单次v1。三手结果共同支持接触保持目标：成功/失败接触步在Linker、XHand、Wuji上均约为155对39，而非由平均关键点误差稳定区分。

## 6. 消融矩阵

| 编号 | 方法 | 回答的问题 |
| --- | --- | --- |
| B0 | 参考逐帧关键点MSE | 官方参考能达到什么水平 |
| B1 | B0 + 掌心相对向量/尺度归一 | 形态差异处理是否有效 |
| B2 | B1 + 速度/加速度平滑 | 时序一致性是否提高重放稳定性 |
| B3 | B2 + 接触保持/法向/穿透 | 几何相似是否真正转化为抓取成功 |
| B4 | B3 + calibration上的全局仿真参数 | 动力学适配能贡献多少 |

每个实验至少记录重放成功率、物体宏平均、类别宏平均、关键点误差、速度/加速度平滑度、穿透率和运行时间。主指标始终是物理重放成功率，不能用优化loss代替。

## 7. 失败分类

失败统一标注为：腕部坐标/尺度错误、接近碰撞、指尖未包络、明显手物穿透、闭合但夹持力不足、抬升滑移、轨迹不平滑引发弹飞、控制器跟踪失败。每种手至少选一个成功和一个典型失败视频，报告中解释“算法目标为何导致这种结果”，而不只展示渲染图。

## 8. 进阶策略

第一选择是每种手单独训练监督BC，避免17天内同时引入复杂跨形态tokenizer。输入使用目标手本体状态、物体位姿/点云几何和可选阶段信息，输出归一化的6+J维位置目标；先做单帧MLP，再加入前两步prop/action的Temporal3。训练曲线记录动作loss，选模必须依据独立验证物体的闭环成功率。

若普通BC出现明显闭环分布偏移，进行一轮DAgger式数据聚合：学生动作推进仿真，在学生访问状态上使用时间对齐的成功重定向轨迹动作作为近似标签，训练batch保持75%离线和25%在线。若严重偏离后时间对齐标签不再合理，则改用参考动作条件残差策略，不宣称是真实专家DAgger。

## 9. 报告主结论边界

基本报告可以声称某算法在冻结的100物体/1000轨迹和三种目标手上提高了仿真重放成功率，但不能外推到真实机器人。进阶报告只有在物体级无泄漏测试上才能声称策略泛化；若策略未超过轨迹重放，也应如实报告distribution shift和数据规模限制，这仍是有价值的研究结论。
