# 重定向代码说明规范

本目录既用于完成考核，也用于代码学习。所有新代码必须让读者不运行程序也能回答：数据从哪里来、经过什么处理、输出到哪里、这个模块解决什么问题。

## 1. 模块文件头

每个Python模块开头必须有中文说明，至少包含：

- 模块作用；
- 主要输入；
- 主要输出；
- 所处流程位置。

示例：

```python
"""可视化Shadow与XHand的关键点对应。

输入：关键点语义配置、两只手的模型资产。
输出：交互HTML、静态PNG和距离JSON。
流程位置：prepare阶段，用于确认映射，不能代替物理评测。
"""
```

## 2. 函数说明

每个函数都要简要写清四项：

```python
def example(source, target):
    """比较源轨迹和目标轨迹。

    输入：source为Shadow轨迹；target为目标手轨迹。
    输出：每帧关键点距离数组。
    逻辑：分别做正向运动学，再计算对应关键点欧氏距离。
    作用：判断重定向后的几何匹配质量。
    """
```

如果函数没有返回值，也要明确写“输出：无返回值；写入哪些文件或修改什么对象”。`main()`需要说明命令行输入和产物。

## 3. 模块索引

新增、删除或改变模块职责时，同时更新 `MODULE_GUIDE.md`。模块索引用于快速学习整体结构，函数docstring用于理解具体代码。

## 4. 自动检查

`test/test_documentation.py`检查 `retargeting/` 下每个Python模块和函数是否有docstring。它只检查“有没有”，人工审查继续判断说明是否准确、清楚。
