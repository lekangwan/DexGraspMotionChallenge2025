# 矢量流程图内容规格

这份文件只定义科研叙事和布局，不用位图生成流程图。连接 Figma MCP 后，应按此规格在同一设计文件中建立两张 16:9 横向矢量图。

## 图一：ShadowHand 自主抓取

主链自左向右：

`GraspM3 专家轨迹` → `DexRep 手物几何表征` → `类别教师与统一学生` → `DAgger 状态纠偏` → `Temporal3 历史` → `Chunk8 动作块` → `时间集成执行` → `Isaac Gym 闭环抓取`

画面分为三层：数据层、学习层、部署层。部署端必须标注“只给初始任务与当前观测，不读取未来专家动作”。在 Chunk8 下方画 8 个小动作块，在时间集成处用重叠窗口表示同一时刻多个预测求均值。

## 图二：三种灵巧手重定向

主链自左向右：

`ShadowHand 70 帧轨迹` → `FK 提取语义几何` → `逐帧运动学初值` → `Isaac Gym 物理重放` → `Global CEM 搜索` → `Rank-5 关节协同优化` → `双重复独立确认` → `1000 条正式评测`

在“运动学初值”处分出三支：Linker、XHand、Wuji，再在物理重放处汇合。Linker 分支额外标注一次 `Global2`。末端画四级漏斗：曾到达目标区、末段保持、稳定、掌物相对运输。

## 视觉约束

- 画布 1920×1080；左右边距 96 px；节点圆角 8 px。
- 背景白色；主文字深蓝灰；主线蓝；物理反馈橙；最终结果绿。
- 每个节点最多两行，每行不超过 12 个汉字；不用 emoji、发光、渐变和拟物图标。
- 箭头统一 2 px，节点等高，模块间距相等；数学细节放脚注，不塞入主流程。
