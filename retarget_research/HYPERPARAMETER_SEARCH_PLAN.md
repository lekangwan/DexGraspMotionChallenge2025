# 正式1000轨迹前的超参数搜索计划

## 1. 数据边界和选择原则

当前20条轨迹已多次用于方法比较，它们从此只是“方法选择集”，不再是独立测试集。所有消融和超参数搜索在这20条上完成；最终候选冻结后，1000条只运行一次最终评测，不因结果再改参数。

每轮都遵守：

1. 所有轨迹共用一组全局参数，不按物体或轨迹选候选并集。
2. 一轮只改变一类有明确物理含义的参数，先粗搜索，只在稳定优势区间做局部细化。
3. 主指标为严格成功数和物体宏平均。若只差1条，继续检查相对当前方法的新增/丢失成功、平均最终抬升、平均最大抬升和接触持续步数。
4. 不选择孤立尖峰。若最高值只在某个单点出现，而相邻参数都明显更差，优先选择更平稳的中间区间。
5. 若搜索边界上的候选最优，只向该方向额外扩展一个点，不无限扩大范围。
6. 成功判据、0.10 m抬升阈值、0.5 s持续时间、物体摩擦和仿真步长是评测协议，不是可调方法超参数。

## 2. Linker O6

### 2.1 已完成：关键点数量

10/11/15点在同一20条上分别为6/20、7/20、7/20。11点相对10点新增FruitBasket30且无回退；15点相对11点2进2退，平均最终抬升还从93.5 mm降到56.5 mm。因此暂以11点进入夹紧搜索。但关键点和夹紧量可能存在交互：找到11点的最佳夹紧量后，还要在10点和15点上各复测该夹紧量。若15点因此反超，再只在15点附近局部细搜，而不盲目做15组全排列。

### 2.2 正在进行：四指渐进夹紧量

搜索点为`0.30/0.425/0.55/0.675/0.80 rad`，拇指固定为`0.10/0.25 rad`。当前0.55是中心；0.30约为其55%，检验过度夹紧；0.80接近四指剩余行程，作为可控的过闭合边界。实际限位审计显示：0.30/0.425/0.55的四指截断率为0，0.675为1.75%，0.80为5.36%，因此范围已覆盖“不足—正常—开始饱和”，无需首轮超过0.80。

粗搜索结果为`0.30:7/20、0.425:8/20、0.55:7/20、0.675:5/20、0.80:6/20`。0.425相对0.55新增Saucepan37和Wingtip17，丢失FruitBasket30，净增1条；平均最终抬升为77.0 mm，低于0.30/0.55的95.3/93.5 mm。因此尚不能只按成功数冻结0.425。仅追加两个区间中点0.3625和0.4875；它们用于区分稳定平台与孤立尖峰，不再继续缩小步长。

局部加密结果为`0.3625:7/20、0.425:8/20、0.4875:6/20`。0.425的成功集合完整包含两个中点的成功集合，相对0.3625额外成功Wingtip17，相对0.4875额外成功Saucepan37和Wingtip17，没有配对回退；全体20条的平均持续抬升时间也为`0.5225/0.5750/0.4975 s`。因此0.425暂作为后续交互消融的夹紧值，但最终冻结前仍要与0.55的FruitBasket30回退一并说明。

在0.425 rad下复测10/11/15点得到`7/8/7`。11点相对10点新增Wingtip17，相对15点新增Wingtip11，两组都没有成功回退；平均持续抬升也以0.575秒最高。因此关键点集最终固定为11点，后续不再搜索10/15点。

### 2.3 后续仅在上一轮选中值附近进行

- 拇指夹紧缩放：`0.5/0.75/1.0`倍，即`(yaw,pitch)=(0.05,0.125)/(0.075,0.1875)/(0.10,0.25) rad`。不向上扩展，因为当前yaw/pitch已有24.1%/35.5%的帧触限，而成功与失败组的拇指触限次数几乎相同。
- 接触启动距离：`15/20/25 mm`。15 mm更晚闭合，25 mm更早闭合；该范围围绕现有20 mm，且小于一节手指的典型尺寸，不会在远离物体时提前闭手。
- 源接触指数：`1/2/3`根，只在最佳距离上测。1根可能过早触发，3根可能对细长物体过严，2根是当前折中。
- 抬升识别位移：`20/30/40 mm`。它决定渐进夹紧在多长的闭合区间内达到全量；不会改变成功判据。
- PD跟踪：`80/3、120/5、200/8`的刚度/阻尼组合，主动与mimic轴使用同值。80更柔顺，200增强跟踪；不再搜到400/20，因为已有独立20条上它没有改变成功数的负结果。

拇指搜索结果为`0.5:7/20、0.75:8/20、1.0:8/20`。0.75和1.0的成功集合、平均持续抬升时间完全相同；0.75将pitch触限率从35.5%降到22.1%，而平均最大/最终抬升仅低2.3/4.3 mm。因此按“同成功时保留更多机械余量”的规则选择0.75，不在0.75–1.0之间继续微调。

接触启动距离15/20/25 mm的成功数为7/8/6。20 mm相对15 mm新增Wingtip17，相对25 mm新增Saucepan37和Wingtip17，均无配对回退；平均持续/最大/最终抬升也全部最高。因此固定20 mm，不在距离上继续细化。

最少接触指数中，1根为6/20，2根为8/20；2根相对1根新增Saucepan37和Wingtip17，无回退。3根在已知成功的Candle轨迹2上不可定义，因该轨迹全70帧最多只有2根指尖进入20 mm。因此固定2根，3根作为不可行消融，不按轨迹回退。

抬升识别位移20/30/40 mm的成功数为7/8/6。30 mm相对20 mm新增Wingtip17且无回退；相对40 mm新增Saucepan37和Wingtip17且无回退。三者平均最大抬升为126.6/131.5/114.2 mm，平均最终抬升为70.5/72.7/57.2 mm，因此固定30 mm。

进入PD搜索前，对当前120/5的20条物理报告进行跟踪审计：6个主动关节平均绝对误差为0.117 rad（约6.7°），5个mimic轴为0.0377 rad（约2.2°），主动/从动手指轴的最坏瞬时误差为1.115 rad（约63.9°）。因此80/3、120/5、200/8不是任意试数：80检查更柔顺的接触能否减少冲击，200检查更强的目标跟踪能否弥补明显滞后，120是当前中心；阻尼随刚度同步增加以抑制振荡。400/20已在另一组20条上出现成功数不增且有成功回退，不重复进入本轮。

PD搜索结果为`80/3:7/20、120/5:8/20、200/8:6/20`。120/5相对80/3新增Wingtip17，相对200/8新增Saucepan37和Wingtip11，两组均无成功回退。主动关节平均绝对误差随增益提高为0.107/0.117/0.101 rad，并非严格单调；即使200/8的误差最小，成功仍最少，说明接触碰撞与物体滑移不能由自由空间跟踪误差替代。120/5位于区间内部且成功集合严格占优，固定该值，不再局部细搜。

### 2.4 昂贵的时序消融，放在接触参数之后

先比较无时序、关节单项、平移单项、旋转单项和当前`1/300/1`组合。当前轨迹上，关节MSE×1、平移MSE×300、旋转角平方×1的平均量级约为`0.00125/0.00606/0.00097`，即平移被有意设为最强的稳定项。若组合最优，再只测`0.3×/1×/3×`总强度，对应`(0.3,90,0.3)/(1,300,1)/(3,900,3)`。不做三个权重的全排列。

实际结果为：无时序9/20、关节单项7/20、平移单项8/20、旋转单项7/20、完整组合8/20。无时序的9条成功严格包含完整组合的8条，额外恢复Saucepan3；相对三个单项也都没有成功回退。无时序虽使平均“每条轨迹的最大关节/平移/旋转跳变”从完整组合的0.489 rad/10.55 mm/0.130 rad增至0.521 rad/10.91 mm/0.160 rad，但平均最终抬升72.7→107.8 mm、接触步84.0→90.3、持续抬升0.575→0.663秒。说明当前时序惩罚确实更平滑，却限制低自由度耦合手逐帧适应当前目标的能力。按预先规则，组合并非最优，因此不搜索整体强度，三项权重全部固定为0。

至此Linker冻结为：11点、无时序、四指0.425 rad、拇指yaw/pitch 0.075/0.1875 rad、接触阈值20 mm、至少2指、抬升阶段30 mm、PD 120/5。方法选择集为9/20；该数值不是最终测试成绩。

## 3. XHand

官方几何基线固定原参数，不调整，以保持“官方方法”对照的可解释性。只搜索我们的指腹细化。

- 首先搜联系最直接的接触权重`1.25/2.5/5.0`。当前5.0下，实际加权接触项平均约1.32，而几何项约0.05，接触已经占主导，因此首轮只向下检查是否过强；若5.0仍是边界最优，才额外测7.5。
- 接触内缩量`-1/-3/-5 mm`。-1 mm偏保守，-5 mm接近当前-6 mm的最深穿透保护，可覆盖从轻触到主动预压的范围。
- 法向权重`0/0.05/0.10`和穿透权重`0/1/2`只做开关+倍增消融。当前两项的实际平均贡献约0.058/0.012，分别与几何项同量级和更小，范围无需更宽。
- 关节先验`0/2/4`。当前实际平均贡献仅0.00038，属于防漂移而非主导项，优先级低于接触权重和内缩量。
- SLSQP `maxeval=10/20/40`，以成功率不下降时的最小值为优先，直接控制正式1000条的时间成本。

接触权重粗搜索结果为`1.25:15/20、2.5:15/20、5.0:16/20`。1.25与2.5成功集合完全相同；5.0完整保留这15条并新增FruitBasket32。平均接触步为125.0/129.3/130.5，平均持续抬升为1.208/1.272/1.301秒，也随权重增强。由于5.0是边界最优，按预案只追加7.5，之后无论结果如何都不再向上扩展。

扩展点7.5为15/20，相对5.0丢失FruitBasket32且没有新增；平均最大/最终抬升267.0/236.0→255.6/233.1 mm，接触步130.5→127.8。因此固定接触权重5.0，不继续扩大范围。下一轮只改变接触目标内缩量-1/-3/-5 mm；-6 mm仍是所有候选共有的最深允许距离，不作为目标值。

接触内缩量结果为`-1 mm:14/20、-3 mm:16/20、-5 mm:15/20`。-3 mm相对-1 mm新增Saucepan37与FruitBasket32，相对-5 mm新增FruitBasket32，两组均无回退；平均接触步为123.7/130.5/129.4，持续抬升为1.179/1.301/1.267秒。因此固定-3 mm，不在1 mm尺度继续加密。

下一轮法向权重0/0.05/0.10中，0表示只追求指腹位置而不要求朝向；法向损失为`(n_pad·n_object+1)^2`，两者反向时为0，即指腹表面面对物体表面。0.05是当前值，0.10检验方向约束倍增是否有益，不扩大到更大值以免朝向项压过接触位置。

法向权重结果为`0:15/20、0.05:16/20、0.10:14/20`。0.05相对关闭法向项新增FruitBasket32，相对0.10新增Canon11和FruitBasket32，均无回退；平均接触步127.2/130.5/122.7，持续抬升1.236/1.301/1.170秒。因此固定0.05。

下一轮穿透权重0/1/2只作用于超过-6 mm的近似深穿透，计算为`relu(-0.006-signed_distance)^2`；它不会惩罚已经选定的-3 mm目标。0检验保护是否多余，2检验更强防穿透是否减少物理碰撞，1为当前中心。

穿透权重0/1/2均为16/20且成功集合完全相同；平均最大抬升为272.6/267.0/273.2 mm，最终抬升266.0/236.0/267.1 mm。0与2的差异仅约0.7/1.1 mm，不能视为可靠性能提升。穿透项在权重1/2时约51%的优化帧非零，说明保护实际参与优化；因此在成功平局时按安全性选择2，同时明确它不是成功率改进，不因位于边界而继续扩大。

下一轮关节先验0/2/4惩罚细化关节偏离官方基线的均方差。0允许接触项自由改变抓形，4更强调保留官方姿态，2是当前值；该项实际贡献较小，所以只做关闭/当前/倍增，不细搜。

关节先验0/2/4均为16/20且成功集合完全相同。平均最大抬升为273.05/273.21/272.74 mm，最终抬升267.23/267.10/267.16 mm，关键点误差5.726/5.724/5.725 mm，差异均可忽略。既然保留官方关节姿态没有可测收益，按最小实现原则选择0，不向更高权重扩展。

最后比较SLSQP `maxeval=10/20/40`。候选全部采用已选中的接触5、法向0.05、穿透2、先验0和-3/-6 mm距离。性能相同则选最小值；更多迭代只有在增加物理成功时才值得正式1000条的额外成本。

XHand迭代上限10/20/40的结果为14/20、16/20、13/20。20相对10新增Saucepan37与FruitBasket32，相对40新增ChocSticks38、Canon4与FruitBasket32，均无回退；平均最终抬升208.7/267.2/214.5 mm。生成墙钟时间约39.5/55.4/89.2秒。20次是成功与成本的内部最优，正式固定20。

XHand至此冻结为：接触权重5、法向0.05、穿透2、关节先验0、目标内缩-3 mm、最深-6 mm、maxeval20；方法选择集16/20，官方XHand对照14/20。两者必须在正式1000条并排报告。

## 4. Wuji

映射v1/v2消融已完成，v1为16/20，v2为12/20，因此后续只使用v1，不取并集。

- SLSQP `maxeval=50/100/150`均为16/20，且成功轨迹集合完全相同。平均关键点误差为11.834/11.821/11.821 mm，平均最终抬升为273.1/272.4/272.5 mm，生成墙钟为802.3/847.0/848.7秒。几何微小差异没有转化为物理收益，因此按预先规则固定`maxeval=50`。
- 50比100在该批次节省约5.3%墙钟；没有继续测试200，因为100到150已经收敛到几乎相同的几何量，也没有新增成功。
- 时序强度`0/0.1/0.3/1.0`倍全部为16/20，并且相对0倍均为新增0、回退0。最大关节步长从1.967 rad依次降到1.174/0.719/0.582 rad，证明时序项确实让轨迹更平滑；但平均最终抬升从273.1 mm逐步降至271.6/269.7/267.5 mm，没有物理收益。因此固定0倍，即三项时序权重均为0，不再向3倍扩展。

Wuji至此冻结为：v1的15点语义映射、maxeval50、平移边界2.0、源高度偏置0.4、无关节/手腕平移/手腕旋转时序约束；方法选择集16/20。

## 5. 执行顺序和停止条件

1. Linker关键点→四指夹紧→拇指→阶段阈值→PD→时序。
2. XHand接触权重→内缩量→法向/穿透/先验消融→迭代数。
3. Wuji迭代数→弱时序。
4. 某分支若相对当前最佳方法净丢失至少2条成功，且平均最终抬升同时下降，则停止该方向，不继续细搜。
5. 三手都冻结后，生成方法配置哈希和一次性正式命令，再进入50类/100物体/1000轨迹。
