# ShadowHand 最终基线与消融

所有结果都使用同一个 Final8 留出集、216 条轨迹、仿真 seed 2025/2026/2027，以及 70 步自主输出后保持末动作 52 步的协议。模型已经在评测前冻结，这些结果只用于报告，不再用于选择模型。

主指标是仓库官方成功条件下的物体宏平均成功率：先分别计算 8 个物体的成功率，再对物体平均，最后对 3 个 seed 求均值。末段稳定官方成功率作为辅助质量指标，30 cm 不再作为主判据。

| 方法 | 官方宏平均 | 稳定官方成功率 | 作用 |
|---|---:|---:|---|
| 仓库发布 BC | 2.46% | 1.39% | 原仓库单物体 checkpoint 直接迁移参考 |
| 同数据官方 BC | 6.76% | 4.17% | 使用相同 80 个训练物体的公平基线 |
| Temporal3 | 12.05% | 12.04% | 旧完整流水线基座 |
| Temporal3 + Demo80 | 11.60% | 9.10% | 单独改变为 80% 示范、20% 教师监督 |
| Chunk8，不做时间集成 | 15.16% | 9.57% | 训练未来 8 步，但每步只执行最新预测 |
| Chunk8 + 等权时间集成 | 36.02% | 35.80% | 融合最近 8 次对当前动作的重叠预测 |
| 最终方法：再加 Z 补偿 | **39.56%** | **39.04%** | 第 40 步后逐渐加入 0.20 归一化腕部上抬 |

最主要的独立增益来自时间集成：相对“Chunk8 不集成”提高 20.86 个百分点。Z 补偿进一步提高 3.54 个百分点，但不是主要提升来源。Demo80 单独略有下降，因此不能声称提高示范权重本身有效；它只有与动作块训练和时间集成组合后才形成最终方案。

Z 补偿也不是对每类都有效：Bottle、Mug、Bowl 的官方类别成功率分别提高约 5.73、7.46、2.50 个百分点，Camera 反而下降约 1.52 个百分点。因此最终结果应表述为整体宏平均和稳定性改善，不能声称四类全部提升。

原始逐 seed 数据见 `summary.yaml`，可用于报告的表格和图片分别是 `final_ablation_table.csv`、`final_ablation.png` 和 `final_ablation.svg`。
